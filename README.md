# Period Tracker Frontend (React)

A mobile-first period tracker with Google Sign-In, built with React, Firebase Auth, Material-UI, and Chart.js.

## Features
- Google Account login (Firebase Auth)
- Track period start date and duration
- View and paginate last 10 cycles
- Visualize cycle length trends (chart)
- Predict next period
- Mobile-first, responsive UI

## Tech Stack
- React (Vite)
- Material-UI
- Firebase JS SDK
- Axios
- Chart.js (react-chartjs-2)
- Day.js

## Usage
- Sign in with Google
- Track your period
- View history, chart, and next prediction
